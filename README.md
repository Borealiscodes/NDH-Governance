🌐 1. Purpose
NDH‑Governance defines the upstream membrane for all NDH systems.  
It establishes:

- altitude rules  
- lineage rules  
- rights‑layer constraints  
- membrane behavior  
- governance primitives  
- provenance geometry  
- spinal architecture  

This repository does not contain execution logic, domain physics, solver mechanics, or coordination systems.  
Those live downstream in their respective membranes (e.g., Spectral Solar Manifold).

---

🧬 2. Spinal Architecture (A0)
NDH‑Governance maintains three governance spines:

Principle Spine
Defines the fundamental rules of altitude, lineage, and membrane behavior.

Navigation Spine
Provides orientation‑only posture for downstream systems.  
Contains the Direction Manifold v1.0, which points toward domain membranes without coordinating them.

Integration Spine (Upstream)
Defines how execution systems inherit governance rules without collapsing altitudes.

These spines stabilize the governance membrane and prevent drift into execution or domain semantics.

---

🧭 3. Direction Manifold (Orientation Layer)
The Direction Manifold provides non‑binding directional posture for NDH systems.  
It clarifies:

- upstream → execution inheritance  
- governance → domain orientation  
- lateral posture across governance sub‑membranes  

It does not:

- route  
- coordinate  
- execute  
- prescribe solver behavior  

It is strictly an A0 orientation artifact.

---

🗺️ 4. Spinal Topology Map
The Spinal Topology Map v1.0 defines the altitude and membrane relationships across:

- A0 — Governance  
- A1 — Execution  
- A10–A12 — Domain (e.g., Spectral Solar Manifold)  

It ensures:

- altitude separation  
- membrane clarity  
- non‑collapse of governance into execution  
- correct posture between repos  

README v3.2 inherits its structure from this topology.

---

🔗 5. Relationship to Downstream Repos
NDH‑Governance is upstream of:

- Spectral Solar Manifold (A10–A12)  
- any future NDH domain membranes  
- any execution systems (A1)  

Governance provides:

- altitude rules  
- lineage rules  
- rights‑layer constraints

Downstream systems provide:

- physics

- engineering constraints  

This relationship is directional, not coordinated.
