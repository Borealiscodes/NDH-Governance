4. Cross-Membrane Interaction Rules

4.1 Math → Physics
Physics may reference math but cannot modify it.

4.2 Physics → Engineering
Engineering must preserve physics constraints.

4.3 Engineering → Code
Code must simulate engineering behavior without altering geometry.

4.4 Humor → All
Humor may reference any membrane but cannot alter lineage.

4.5 Rights-Layer → All
Rights-layer may validate any artifact but cannot generate content.

4.6 Governance → All
Governance defines rules but does not produce domain artifacts.

ASCII:

`
Governance → Rights-Layer → All Membranes
`
