⭐ Topology Summary (Spinal, Not Flow)

A0 — Governance Membrane
- Principle Spine  
  Defines altitude, lineage, rights‑layer, membrane behavior.
- Navigation Spine  
  Orientation‑only; includes the Direction Manifold.
- Integration Spine (Upstream)  
  Defines how execution inherits governance.

A1 — Execution Membrane
- Runtime solver logic  
- Update loops  
- Stability envelopes  
- Execution inheritance from A0

A10–A12 — Domain Membrane (Repo B: SSM)
- Spectral geometry  
- Solar physics  
- Harmonic resonance  
- Curvature engines  
- Metamaterial constraints  
- Fabrication tolerances  
- Domain provenance

---

⭐ Altitude Relationships

A0 → A1 (Upstream Binding)
Governance defines rules; execution inherits them.

A0 → A10 (Downstream Orientation)
Governance points toward domain systems without coordinating them.

A1 → A10 (Execution → Domain)
Execution systems operate on domain physics.

A10 → A0 (Provenance Return)
Domain outputs return lineage + rights‑layer compliance upstream.

---

⭐ Membrane Boundaries (Critical)

- A0 must not contain domain physics.  
- A10 must not contain governance rules.  
- A1 must not coordinate repos.  
- Navigation Spine must not route.  
- Direction Manifold must not prescribe behavior.

This topology prevents altitude collapse and keeps NDH stable.
